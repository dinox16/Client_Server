================================================================================
KEY FEATURES IMPLEMENTED
================================================================================

1. End-to-End Encryption (E2EE):
   - RSA 2048-bit key pairs
   - AES-256-EAX symmetric encryption
   - Hybrid encryption (RSA for key exchange, AES for data)
   - Perfect Forward Secrecy (unique AES key per message)

2. Digital Signatures:
   - SHA-256 hashing
   - RSA signature generation and verification
   - Message authentication

3. Blockchain:
   - Block structure with index, timestamp, data, hash
   - Proof of Work mining (difficulty = 2)
   - Chain validation and tampering detection
   - Message history tracking

4. Server Features:
   - TCP socket server (0.0.0.0:5555)
   - Multi-client support with threading
   - Encrypted message relay (no decryption)
   - User list broadcast with public keys

5. Security Demonstrations:
   - Malware simulation showing failed decryption attempts
   - Defense demo proving E2EE protection
   - Attack scenario with compromised client

================================================================================
SECURITY GUARANTEES
================================================================================

1. Confidentiality:
   - Messages encrypted before transmission
   - Only recipient can decrypt (private key required)
   - Server never sees plaintext

2. Authentication:
   - Digital signatures verify sender identity
   - Public key infrastructure (PKI)
   - Signature verification before display

3. Integrity:
   - Blockchain immutability
   - Tampering detection
   - Hash chain validation

4. Malware Resistance:
   - Attacker cannot decrypt without private key
   - Attacker cannot forge signatures
   - Attacker cannot modify blockchain undetected
